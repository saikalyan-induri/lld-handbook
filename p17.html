A. Realistic Interview Prompt

"Design a movie ticket booking system like BookMyShow. Users can browse shows, select seats, hold them briefly while paying, and confirm a booking. Thousands of users may try to book seats for a popular show at the same time."

B. Difficulty

Advanced — the concurrency showcase of this document's second half. The entity model is not the hard part; the hard part is that every popular-show demo scenario is a high-contention multi-seat race, and the interview is really evaluating whether the candidate's locking design survives that contention without deadlocking, double-booking, or leaving seats stuck in limbo.

C. What This Problem Tests

  • Splitting the physical Seat from its per-show status (ShowSeat) — the same "shared static thing vs. per-instance changing state" split as Library's Book/BookItem and Hotel's Room/RoomInventory, now at genuinely high contention
  • State machine for a seat's per-show lifecycle (available → locked → booked, with expiry back to available)
  • TTL-based soft locking during payment, converted to a hard commit only on payment success
  • Multi-seat atomicity: booking several seats together must be all-or-nothing and deadlock-free
  • Idempotent payment confirmation under retries

D. Requirements

Functional

  1. Browse shows for a movie by city/theater/time
  2. View a show's seat map with real-time availability
  3. Select one or more seats and hold them temporarily while completing payment
  4. Confirm a booking on successful payment; release the hold on failure or timeout
  5. Price seats by category (Silver/Gold/Premium) and show (peak/off-peak)

Non-Functional

  • Two users must never both successfully book the same seat for the same show
  • A user who abandons checkout must not permanently lock a seat — the hold must expire
  • Booking multiple seats together must not deadlock against another user doing the same for an overlapping seat set

F. Assumptions

  • Confirmed: show browsing, seat-map viewing, temporary seat hold, payment-gated confirmation, category/show-based pricing.
  • Assumption: holds expire after a fixed TTL (e.g. 5–10 minutes) unless stated otherwise.
  • Assumption: payment confirmation arrives via a callback/webhook that may be retried by the payment provider, so it must be handled idempotently.

I. Class Relationships

  • Seat vs. ShowSeat is the central modeling decision, once again: a seat's physical attributes (number, category) are static across every show that ever plays in that screen, while its booking status only makes sense relative to one specific show — the same seat is available for the 3pm show and booked for the 7pm show. This is the identical split-shape already seen in Library's Book/BookItem and Hotel's Room/RoomInventory, but the contention here is dramatically higher because a single popular show creates a genuine thundering-herd on a small set of good seats.
  • State machine for ShowSeat: AVAILABLE → LOCKED → BOOKED, with LOCKED → AVAILABLE on hold expiry or payment failure. Encoding this as a ShowSeatState hierarchy (rather than a raw enum checked with scattered if statements) keeps every transition's legality colocated with the state itself — a BOOKED seat simply has no onLock() transition to accept.
  • SeatLock as a TTL-bound soft hold, Booking confirmation as the hard commit: selecting seats doesn't book them — it soft-locks them for a bounded window so the seat isn't shown as available to other users while this user pays, but the lock self-expires if they abandon checkout. Only a successful payment converts the soft lock into a permanent BOOKED status. This two-phase shape is deliberately similar to a database's optimistic-lock-then-commit pattern, made explicit at the domain level.
  • Strategy for pricing, Observer for the waitlist: both are the same shapes already established in Hotel (Problem 16) and Library (Problem 15) respectively — pricing varies by seat category and show timing behind PricingStrategy, and waitlist notification on a cancellation reuses the same subject/observer relationship rather than a bespoke path.

O. Design Evolution

  • V1: one booked boolean per seat, no hold concept, one flat price, synchronous payment.
  • V2: split Seat from ShowSeat the moment a screen hosts more than one show — the "same seat, different show" case that a single boolean cannot represent.
  • V3: introduce the ShowSeatState machine and SeatLock TTL once "hold while paying" becomes a real requirement rather than instant booking.
  • V4: extract PricingStrategy once category/show-based pricing is requested.
  • V5: wire WaitlistNotifier once sold-out waitlisting is requested.

What stays stable: BookingService's public hold/confirm/cancel API. New states and pricing rules are additive.

Booking confirmBooking(String lockId, PaymentResult paymentResult, String idempotencyKey) {
  if (alreadyProcessed(idempotencyKey)) { return existingBookingFor(idempotencyKey); }  // idempotent retry
  SeatLock seatLock = lockFor(lockId);
  if (seatLock.isExpired()) { reject(); }
  Booking booking;
  if (paymentResult.isSuccess()) {
    for (ShowSeat seat : seatLock.getSeats()) { seat.setStatus(BOOKED); }
    booking = new Booking(seatLock, CONFIRMED);

    for (ShowSeat seat : seatLock.getSeats()) { seat.setStatus(AVAILABLE); }
    waitlistNotifier.notifyWaiting(seatLock.getSeats());
  }
  recordProcessed(idempotencyKey, booking);
  return booking;
}

U. Testing Strategy

  • Happy path: holding then confirming a set of seats transitions exactly those seats to BOOKED and no others.
  • Edge cases: a hold that expires before payment completes releases all its seats back to AVAILABLE and, if a waitlist exists, triggers notification.
  • Idempotency tests: calling confirmBooking() twice with the same idempotency key produces exactly one Booking and one charge, not two.
  • Concurrency tests: two users concurrently holding overlapping seat sets (e.g. user A wants A4-A5, user B wants A5-A6) result in exactly one success for the shared seat A5, and neither request deadlocks against the other.

W. Concurrency

Shared mutable state: each ShowSeat's status for a popular show, under genuinely high simultaneous contention — this is the highest-contention scenario in the entire document.

  • The check-then-act race, at multi-resource scale: holding a single seat has the same check-then-lock-then-commit shape seen throughout this document (Parking Lot, Splitwise, ATM, Library, Hotel). What's new here is that a booking often spans multiple seats, which introduces a genuine deadlock risk: if user A locks A4 then tries to lock A5 while user B has already locked A5 and is trying to lock A4, both wait on each other forever.
  • Canonical lock ordering resolves it: sorting the requested seat ids before acquiring any locks, and always acquiring in that sorted order, guarantees every concurrent request converges on the same global lock order — this is exactly File System's (Problem 9) inter-process lock-ordering fix for the same deadlock shape, reapplied to seats instead of files.
  • TTL-based soft locks prevent indefinite holds: a SeatLock that never expired would let an abandoned checkout permanently starve a seat; the TTL guarantees eventual release even if the client disappears mid-payment.
  • Idempotent confirmation under retries: payment webhooks can and do get retried by the provider; keying confirmBooking() on an idempotency key prevents a retry from double-booking or double-charging — the same lesson Pub-Sub (Problem 10) established for message redelivery.

X. Persistence

Bookings and confirmed seat status must survive a restart without question — a booking that vanishes after payment is a trust-destroying failure. Seat holds are a middle ground: they could technically be rebuilt from a fast in-memory/distributed cache (with the TTL as the natural expiry), but the confirmed Booking record itself is always durable, repository-backed data.

Z. Failure Scenarios

  • Payment gateway times out with an unknown result: the seat must stay LOCKED (not auto-release, not auto-confirm) until an explicit success/failure callback or a manual reconciliation job resolves it — assuming either outcome is a correctness bug in one direction or the other.
  • The service crashes between locking seats and returning the SeatLock to the caller: a background sweep that releases any lock past its TTL guarantees seats don't stay stuck forever even if the in-flight request never got its response.

AA. Common Bad Designs

  • A single booked boolean per seat, shared across all shows — the defining mistake for this problem; see I.
  • Locking seats one at a time in whatever order the caller happened to request them — the deadlock trap; see W.
  • No TTL on a seat hold — an abandoned checkout permanently locks a seat no one else can ever book.
  • Treating payment confirmation as safe to process more than once — without an idempotency key, a retried webhook can double-book or double-charge.

AC. Interviewer Evaluation

Strong signal: splitting Seat/ShowSeat unprompted; proposing a TTL-bound hold before being asked how checkout abandonment is handled; independently identifying the multi-seat deadlock risk and fixing it with canonical lock ordering; flagging idempotency for payment confirmation without being prompted.

Red flag: one booked flag per seat; per-seat locking with no defined acquisition order; no hold expiry; treating payment confirmation as safe to run twice.

AD. Interview Simulation

Interviewer: Design a movie ticket booking system for a popular show with thousands of concurrent users.
Candidate: I'd split the physical Seat from ShowSeat, since booking status only makes sense relative to one specific show — the same seat is free for one showtime and booked for another. Each ShowSeat runs a small state machine: available, locked, booked.
Interviewer: What happens between selecting a seat and actually paying for it?
Candidate: Selecting seats acquires a TTL-bound SeatLock — a soft hold, not a booking. If payment succeeds within the window, the hold converts to a permanent BOOKED status; if it fails or the TTL expires, the seats revert to available automatically.
Interviewer: What if a user tries to book two seats, and another user is simultaneously trying to book an overlapping pair in the opposite order?
Candidate: That's a real deadlock risk if each request locks seats in whatever order the user clicked them. I'd sort the requested seat ids and always acquire locks in that canonical sorted order — the same fix I'd use for the file-lock-ordering problem — so every concurrent request converges on the same global order and none of them can circularly wait on each other.
Interviewer: The payment provider retries its confirmation webhook due to a network blip. What happens?
Candidate: confirmBooking() is keyed by an idempotency key derived from the payment transaction id. A retried call with the same key returns the already-created booking instead of creating a second one or charging twice.

/**
 * Problem 17: Movie Ticket Booking System (Concurrency Showcase)
 *
 * Key design decisions faithfully reproduced from the class diagram:
 *  - Seat (static attrs) vs ShowSeat (per-show status) split.
 *  - ShowSeatState hierarchy encodes AVAILABLE -> LOCKED -> BOOKED legality, and LOCKED/BOOKED -> AVAILABLE on expire/release.
 *  - SeatLock is a TTL-bound soft hold; only a successful payment converts it into a Booking confirmation.
 *  - PricingStrategy is injected (Strategy); WaitlistNotifier is an Observer subject.
 *  - BookingService is the facade; holdSeats() locks seats in canonical (sorted) order to avoid deadlock
 *    against another user holding an overlapping seat set.
 */
public class p17 {

    enum SeatCategory { SILVER, GOLD, PREMIUM }
    enum ShowSeatStatus { AVAILABLE, LOCKED, BOOKED }
    enum BookingStatus { HOLD, CONFIRMED, CANCELLED }

    static final class User {
        final String id, name;
        User(String id, String name) { this.id = id; this.name = name; }
    }

    static final class PaymentResult {
        final boolean success;
        PaymentResult(boolean success) { this.success = success; }

    // ---------- Seat / Show ----------

    static final class Seat {
        final String seatNumber;
        final SeatCategory category;
        Seat(String seatNumber, SeatCategory category) { this.seatNumber = seatNumber; this.category = category; }
    }

    static final class Movie {
        final String id, title;
        final int durationMinutes;
        Movie(String id, String title, int durationMinutes) { this.id = id; this.title = title; this.durationMinutes = durationMinutes; }
    }

    static final class Screen {
        final String id, name;
        final List<Seat> seats;
        Screen(String id, String name, List<Seat> seats) { this.id = id; this.name = name; this.seats = seats; }
    }

    static final class Show {
        final String id;
        final Movie movie;
        final Screen screen;
        final LocalDateTime startTime;
        private final Map<String, ShowSeat> showSeats = new LinkedHashMap<>();

        Show(String id, Movie movie, Screen screen, LocalDateTime startTime) {
            this.id = id;
            this.movie = movie;
            this.screen = screen;
            this.startTime = startTime;
            // One ShowSeat per physical seat -- the same Seat is independently bookable per Show.
            for (Seat seat : screen.seats) showSeats.put(seat.seatNumber, new ShowSeat(seat, this));
        }

        ShowSeat getShowSeat(String seatNumber) {
            ShowSeat seat = showSeats.get(seatNumber);
            if (seat == null) throw new NoSuchElementException("No such seat: " + seatNumber);
            return seat;
        }
    }

    // ---------- ShowSeatState (State pattern) ----------

    interface ShowSeatState {
        void onLock(ShowSeat seat);
        void onConfirm(ShowSeat seat);
        void onExpire(ShowSeat seat);
    }

    static final class AvailableState implements ShowSeatState {
        static final AvailableState INSTANCE = new AvailableState();
        public void onLock(ShowSeat seat) { seat.setState(ShowSeatStatus.LOCKED, LockedState.INSTANCE); }
        public void onConfirm(ShowSeat seat) { throw new IllegalStateException("Cannot confirm a seat that was never locked"); }
        public void onExpire(ShowSeat seat) { /* already available; no-op */ }
    }

    static final class LockedState implements ShowSeatState {
        static final LockedState INSTANCE = new LockedState();
        public void onLock(ShowSeat seat) { throw new IllegalStateException("Seat already locked"); }
        public void onConfirm(ShowSeat seat) { seat.setState(ShowSeatStatus.BOOKED, BookedState.INSTANCE); }
        public void onExpire(ShowSeat seat) { seat.setState(ShowSeatStatus.AVAILABLE, AvailableState.INSTANCE); }
    }

    static final class BookedState implements ShowSeatState {
        static final BookedState INSTANCE = new BookedState();
        public void onLock(ShowSeat seat) { throw new IllegalStateException("Seat already booked"); }
        public void onConfirm(ShowSeat seat) { throw new IllegalStateException("Seat already booked"); }
        // Freeing a booked seat (e.g. booking cancellation) returns it to the pool.
        public void onExpire(ShowSeat seat) { seat.setState(ShowSeatStatus.AVAILABLE, AvailableState.INSTANCE); }
    }

    // ---------- ShowSeat ----------

    static final class ShowSeat {
        final Seat seat;
        final Show show;
        private volatile ShowSeatStatus status = ShowSeatStatus.AVAILABLE;
        private ShowSeatState state = AvailableState.INSTANCE;
        private final Lock lock = new ReentrantLock();

        ShowSeat(Seat seat, Show show) { this.seat = seat; this.show = show; }

        void setState(ShowSeatStatus status, ShowSeatState state) { this.status = status; this.state = state; }
        ShowSeatStatus getStatus() { return status; }

        /** Soft-lock this seat for a pending hold. Throws if not currently AVAILABLE. */
        void lock() {
            lock.lock();
            try { state.onLock(this); } finally { lock.unlock(); }
        }

        /** Hard-commit: LOCKED -> BOOKED. */
        void confirm() {
            lock.lock();
            try { state.onConfirm(this); } finally { lock.unlock(); }
        }

        /** Free the seat back to AVAILABLE -- used for hold expiry, payment failure, or booking cancellation. */
        void release() {
            lock.lock();
            try { state.onExpire(this); } finally { lock.unlock(); }
        }
    }

    // ---------- SeatLock ----------

    static final class SeatLock {
        final String id;
        final User user;
        final List<ShowSeat> seats;
        final long expiresAt; // epoch millis

        SeatLock(String id, User user, List<ShowSeat> seats, long expiresAt) {
            this.id = id; this.user = user; this.seats = seats; this.expiresAt = expiresAt;
        }

        boolean isExpired() { return System.currentTimeMillis() > expiresAt; }
    }

    // ---------- PricingStrategy ----------

    interface PricingStrategy {
        double calculatePrice(Seat seat, Show show);
    }

    static final class CategoryTimeBasedPricingStrategy implements PricingStrategy {
        private final Map<SeatCategory, Double> baseRates = Map.of(
                SeatCategory.SILVER, 100.0, SeatCategory.GOLD, 180.0, SeatCategory.PREMIUM, 280.0);

        public double calculatePrice(Seat seat, Show show) {
            double base = baseRates.get(seat.category);
            int hour = show.startTime.getHour();
            boolean peak = hour >= 18 && hour < 22; // evening peak window
            return peak ? base * 1.3 : base;
        }
    }

    // ---------- Booking ----------

    static final class Booking {
        final String id;
        final User user;
        final Show show;
        final List<ShowSeat> seats;
        BookingStatus status;
        final double totalPrice;

        Booking(String id, User user, Show show, List<ShowSeat> seats, PricingStrategy pricingStrategy) {
            this.id = id; this.user = user; this.show = show; this.seats = seats;
            this.status = BookingStatus.HOLD;
            double total = 0;
            for (ShowSeat s : seats) total += pricingStrategy.calculatePrice(s.seat, show);
            this.totalPrice = total;
        }

        void confirm() {
            for (ShowSeat s : seats) s.confirm();
            status = BookingStatus.CONFIRMED;
        }

        void cancel() {
            for (ShowSeat s : seats) s.release();
            status = BookingStatus.CANCELLED;
        }
    }

    // ---------- WaitlistNotifier (Observer) ----------

    interface WaitlistObserver {
        void onSeatAvailable(ShowSeat seat);
    }

    static final class WaitlistNotifier {
        private final List<WaitlistObserver> observers = new ArrayList<>();
        void subscribe(WaitlistObserver observer) { observers.add(observer); }
        void notifyWaiting(List<ShowSeat> freedSeats) {
            for (ShowSeat seat : freedSeats) for (WaitlistObserver o : observers) o.onSeatAvailable(seat);
        }
    }

    static final class ConsoleWaitlistNotifier implements WaitlistObserver {
        public void onSeatAvailable(ShowSeat seat) {
            System.out.printf("[waitlist] Seat %s on show %s is available again%n", seat.seat.seatNumber, seat.show.id);
        }
    }

    // ---------- BookingService (facade) ----------

    static final class BookingService {
        private static final long HOLD_TTL_MILLIS = 2000;
        private final PricingStrategy pricingStrategy;
        private final WaitlistNotifier waitlistNotifier;
        private final Map<String, SeatLock> activeLocks = new HashMap<>();
        private final Map<String, Booking> bookings = new HashMap<>();
        private final Map<String, Booking> idempotencyRecords = new HashMap<>();
        private int lockSeq = 0, bookingSeq = 0;

        BookingService(PricingStrategy pricingStrategy, WaitlistNotifier waitlistNotifier) {
            this.pricingStrategy = pricingStrategy;
            this.waitlistNotifier = waitlistNotifier;
        }

        /** Locks seats in canonical (sorted) order so two overlapping multi-seat holds never deadlock. */
        synchronized SeatLock holdSeats(User user, Show show, List<String> seatNumbers) {
            List<String> ordered = new ArrayList<>(seatNumbers);
            Collections.sort(ordered);
            List<ShowSeat> locked = new ArrayList<>();
            try {
                for (String id : ordered) {
                    ShowSeat seat = show.getShowSeat(id);
                    seat.lock(); // throws IllegalStateException if not AVAILABLE
                    locked.add(seat);
                }
            } catch (IllegalStateException rejected) {
                for (ShowSeat seat : locked) seat.release(); // rollback partial holds
                throw new IllegalStateException("Could not hold all requested seats: " + rejected.getMessage());
            }
            String lockId = "LOCK-" + (++lockSeq);
            SeatLock seatLock = new SeatLock(lockId, user, locked, System.currentTimeMillis() + HOLD_TTL_MILLIS);
            activeLocks.put(lockId, seatLock);
            return seatLock;
        }

        synchronized Booking confirmBooking(String lockId, PaymentResult paymentResult, String idempotencyKey) {
            if (idempotencyRecords.containsKey(idempotencyKey)) return idempotencyRecords.get(idempotencyKey); // idempotent retry

            SeatLock seatLock = activeLocks.get(lockId);
            if (seatLock == null) throw new NoSuchElementException("Unknown or already-consumed lock " + lockId);
            if (seatLock.isExpired()) {
                activeLocks.remove(lockId);
                for (ShowSeat seat : seatLock.seats) seat.release();
                throw new IllegalStateException("Seat hold expired for lock " + lockId);
            }

            Booking booking = new Booking("BKG-" + (++bookingSeq), seatLock.user, seatLock.seats.get(0).show, seatLock.seats, pricingStrategy);
            if (paymentResult.success) {
                booking.confirm();
            } else {
                booking.cancel();
                waitlistNotifier.notifyWaiting(seatLock.seats);
            }
            activeLocks.remove(lockId);
            bookings.put(booking.id, booking);
            idempotencyRecords.put(idempotencyKey, booking);
            return booking;
        }

        synchronized void cancelBooking(String bookingId) {
            Booking booking = bookings.get(bookingId);
            if (booking == null) throw new NoSuchElementException("Unknown booking " + bookingId);
            booking.cancel();
            waitlistNotifier.notifyWaiting(booking.seats);
        }
    }

    // ---------- Demo ----------

    public static void main(String[] args) throws InterruptedException {
        List<Seat> seats = List.of(
                new Seat("A1", SeatCategory.PREMIUM), new Seat("A2", SeatCategory.PREMIUM),
                new Seat("B1", SeatCategory.GOLD), new Seat("B2", SeatCategory.GOLD),
                new Seat("C1", SeatCategory.SILVER), new Seat("C2", SeatCategory.SILVER));
        Screen screen = new Screen("SCR-1", "Screen 1", seats);
        Movie movie = new Movie("MOV-1", "Interstellar", 169);
        Show show = new Show("SHOW-1", movie, screen, LocalDateTime.of(2026, 10, 2, 19, 0)); // peak hour

        WaitlistNotifier waitlistNotifier = new WaitlistNotifier();
        waitlistNotifier.subscribe(new ConsoleWaitlistNotifier());
        BookingService bookingService = new BookingService(new CategoryTimeBasedPricingStrategy(), waitlistNotifier);

        User alice = new User("u1", "Alice");
        User bob = new User("u2", "Bob");

        // Concurrency demo: Alice holds {A1,A2}, Bob holds {A2,B1} -- overlapping sets, sorted-order locking prevents deadlock.
        final SeatLock[] results = new SeatLock[2];
        Thread t1 = new Thread(() -> {
            try { results[0] = bookingService.holdSeats(alice, show, List.of("A1", "A2")); } catch (Exception ignored) { }
        });
        Thread t2 = new Thread(() -> {
            try { results[1] = bookingService.holdSeats(bob, show, List.of("A2", "B1")); } catch (Exception e) {
                System.out.println("Bob's hold rejected (expected, contends on A2): " + e.getMessage());
            }
        });
        t1.start(); t2.start();
        t1.join(); t2.join();

        SeatLock aliceLock = results[0];
        System.out.println("Alice locked seats: " + aliceLock.seats.size() + " totalPrice will be computed at confirm");

        Booking booking = bookingService.confirmBooking(aliceLock.id, new PaymentResult(true), "idem-key-1");
        System.out.printf("Booking %s CONFIRMED, total=%.2f%n", booking.id, booking.totalPrice);

        // Idempotent retry with the same key returns the same booking, no double charge/booking.
        Booking retry = bookingService.confirmBooking(aliceLock.id, new PaymentResult(true), "idem-key-1");
        System.out.println("Idempotent retry returns same booking: " + (retry == booking));

        // Bob can now hold A2 since Alice's booking only used A1 -- retry with a valid, non-conflicting set.
        SeatLock bobLock = bookingService.holdSeats(bob, show, List.of("B1", "B2"));
        Booking failedPayment = bookingService.confirmBooking(bobLock.id, new PaymentResult(false), "idem-key-2");
        System.out.println("Bob's failed-payment booking status: " + failedPayment.status + " (seats released, waitlist notified)");

        // Cancel Alice's confirmed booking, freeing A1 and A2 back to the pool.
        bookingService.cancelBooking(booking.id);
        System.out.println("A1 status after cancellation: " + show.getShowSeat("A1").getStatus());
        System.out.println("A2 status after cancellation: " + show.getShowSeat("A2").getStatus());

        // TTL expiry demo: hold C1, let it expire, then confirming should be rejected.
        SeatLock shortLock = bookingService.holdSeats(alice, show, List.of("C1"));
        Thread.sleep(2100);
        try {
            bookingService.confirmBooking(shortLock.id, new PaymentResult(true), "idem-key-3");
        } catch (IllegalStateException e) {
            System.out.println("Expired hold correctly rejected: " + e.getMessage());
        }
        System.out.println("C1 status after expiry: " + show.getShowSeat("C1").getStatus());
    }
}

class BookingService {
public:
    BookingService(std::shared_ptr<PricingStrategy> pricingStrategy, std::shared_ptr<WaitlistNotifier> waitlistNotifier)
        : pricingStrategy_(std::move(pricingStrategy)), waitlistNotifier_(std::move(waitlistNotifier)) {}

    // Locks seats in canonical (sorted) order so two overlapping multi-seat holds never deadlock.
    std::shared_ptr<SeatLock> holdSeats(const User& user, Show& show, std::vector<std::string> seatNumbers) {
        std::lock_guard<std::mutex> g(serviceMutex_); // coarse-grained: whole hold operation is atomic
        std::sort(seatNumbers.begin(), seatNumbers.end());
        std::vector<ShowSeat*> locked;
        try {
            for (auto& id : seatNumbers) {
                ShowSeat& seat = show.getShowSeat(id);
                seat.lock(); // throws if not AVAILABLE
                locked.push_back(&seat);
            }
        } catch (const std::exception& rejected) {
            for (auto* seat : locked) seat->release(); // rollback partial holds
            throw std::runtime_error(std::string("Could not hold all requested seats: ") + rejected.what());
        }
        auto lock = std::make_shared<SeatLock>();
        lock->id = "LOCK-" + std::to_string(++lockSeq_);
        lock->user = user;
        lock->seats = locked;
        lock->expiresAt = std::chrono::steady_clock::now() + std::chrono::milliseconds(2000);
        activeLocks_[lock->id] = lock;
        return lock;
    }

    std::shared_ptr<Booking> confirmBooking(const std::string& lockId, PaymentResult paymentResult, const std::string& idempotencyKey) {
        std::lock_guard<std::mutex> g(serviceMutex_);
        auto idemIt = idempotencyRecords_.find(idempotencyKey);
        if (idemIt != idempotencyRecords_.end()) return idemIt->second; // idempotent retry

        auto lockIt = activeLocks_.find(lockId);
        if (lockIt == activeLocks_.end()) throw std::runtime_error("Unknown or already-consumed lock " + lockId);
        auto seatLock = lockIt->second;
        if (seatLock->isExpired()) {
            activeLocks_.erase(lockId);
            for (auto* seat : seatLock->seats) seat->release();
            throw std::runtime_error("Seat hold expired for lock " + lockId);
        }

        auto booking = std::make_shared<Booking>("BKG-" + std::to_string(++bookingSeq_), seatLock->user,
                                                   seatLock->seats[0]->show, seatLock->seats, *pricingStrategy_);
        if (paymentResult.success) {
            booking->confirm();
        } else {
            booking->cancel();
            waitlistNotifier_->notifyWaiting(seatLock->seats);
        }
        activeLocks_.erase(lockId);
        bookings_[booking->id] = booking;
        idempotencyRecords_[idempotencyKey] = booking;
        return booking;
    }

    void cancelBooking(const std::string& bookingId) {
        std::lock_guard<std::mutex> g(serviceMutex_);
        auto it = bookings_.find(bookingId);
        if (it == bookings_.end()) throw std::runtime_error("Unknown booking " + bookingId);
        it->second->cancel();
        waitlistNotifier_->notifyWaiting(it->second->seats);
    }

private:
    std::shared_ptr<PricingStrategy> pricingStrategy_;
    std::shared_ptr<WaitlistNotifier> waitlistNotifier_;
    std::map<std::string, std::shared_ptr<SeatLock>> activeLocks_;
    std::map<std::string, std::shared_ptr<Booking>> bookings_;
    std::map<std::string, std::shared_ptr<Booking>> idempotencyRecords_;
    std::mutex serviceMutex_;
    int lockSeq_ = 0, bookingSeq_ = 0;
};

/** A minimal FIFO mutual-exclusion primitive: a queue of waiters, one holder at a time. */
class AsyncMutex {
  constructor() { this._locked = false; this._waiters = []; }
  _acquire() {
    return new Promise((resolve) => {
      if (!this._locked) { this._locked = true; resolve(); }
      else this._waiters.push(resolve);
    });
  }
  _release() {
    if (this._waiters.length > 0) this._waiters.shift()();
    else this._locked = false;
  }
  async runExclusive(fn) {
    await this._acquire();
    try { return await fn(); } finally { this._release(); }
  }
}

class BookingService {
  static HOLD_TTL_MILLIS = 2000;

  constructor(pricingStrategy, waitlistNotifier) {
    this._pricingStrategy = pricingStrategy;
    this._waitlistNotifier = waitlistNotifier;
    this._activeLocks = new Map();
    this._bookings = new Map();
    this._idempotencyRecords = new Map();
    this._serviceMutex = new AsyncMutex(); // coarse-grained: whole hold/confirm operation is atomic
    this._lockSeq = 0;
    this._bookingSeq = 0;
  }

  async holdSeats(user, show, seatNumbers) {
    return this._serviceMutex.runExclusive(async () => {
      const ordered = [...seatNumbers].sort();
      const locked = [];
      try {
        for (const id of ordered) {
          const seat = show.getShowSeat(id);
          await seat.lock(); // throws if not AVAILABLE
          locked.push(seat);
        }
      } catch (rejected) {
        for (const seat of locked) await seat.release(); // rollback partial holds
        throw new Error(`Could not hold all requested seats: ${rejected.message}`);
      }
      const lockId = `LOCK-${++this._lockSeq}`;
      const seatLock = new SeatLock(lockId, user, locked, BookingService.HOLD_TTL_MILLIS);
      this._activeLocks.set(lockId, seatLock);
      return seatLock;
    });
  }

  async confirmBooking(lockId, paymentResult, idempotencyKey) {
    return this._serviceMutex.runExclusive(async () => {
      if (this._idempotencyRecords.has(idempotencyKey)) return this._idempotencyRecords.get(idempotencyKey);

      const seatLock = this._activeLocks.get(lockId);
      if (!seatLock) throw new Error(`Unknown or already-consumed lock ${lockId}`);
      if (seatLock.isExpired()) {
        this._activeLocks.delete(lockId);
        for (const seat of seatLock.seats) await seat.release();
        throw new Error(`Seat hold expired for lock ${lockId}`);
      }

      const booking = new Booking(`BKG-${++this._bookingSeq}`, seatLock.user, seatLock.seats[0].show, seatLock.seats, this._pricingStrategy);
      if (paymentResult.success) {
        await booking.confirm();
      } else {
        await booking.cancel();
        this._waitlistNotifier.notifyWaiting(seatLock.seats);
      }
      this._activeLocks.delete(lockId);
      this._bookings.set(booking.id, booking);
      this._idempotencyRecords.set(idempotencyKey, booking);
      return booking;
    });
  }

  async cancelBooking(bookingId) {
    return this._serviceMutex.runExclusive(async () => {
      const booking = this._bookings.get(bookingId);
      if (!booking) throw new Error(`Unknown booking ${bookingId}`);
      await booking.cancel();
      this._waitlistNotifier.notifyWaiting(booking.seats);
    });
  }
}

      try {
        for (const id of ordered) {
          const seat = show.getShowSeat(id);
          await seat.lock(); // throws if not AVAILABLE
          locked.push(seat);
        }
      } catch (rejected: any) {
        for (const seat of locked) await seat.release(); // rollback partial holds
        throw new Error(`Could not hold all requested seats: ${rejected.message}`);
      }
      const lockId = `LOCK-${++this.lockSeq}`;
      const seatLock = new SeatLock(lockId, user, locked, BookingService.HOLD_TTL_MILLIS);
      this.activeLocks.set(lockId, seatLock);
      return seatLock;
    });
  }

  async confirmBooking(lockId: string, paymentResult: PaymentResult, idempotencyKey: string): Promise<Booking> {
    return this.serviceMutex.runExclusive(async () => {
      const existing = this.idempotencyRecords.get(idempotencyKey);
      if (existing) return existing;

      const seatLock = this.activeLocks.get(lockId);
      if (!seatLock) throw new Error(`Unknown or already-consumed lock ${lockId}`);
      if (seatLock.isExpired()) {
        this.activeLocks.delete(lockId);
        for (const seat of seatLock.seats) await seat.release();
        throw new Error(`Seat hold expired for lock ${lockId}`);
      }

      const booking = new Booking(`BKG-${++this.bookingSeq}`, seatLock.user, seatLock.seats[0].show, seatLock.seats, this.pricingStrategy);
      if (paymentResult.success) {
        await booking.confirm();
      } else {
        await booking.cancel();
        this.waitlistNotifier.notifyWaiting(seatLock.seats);
      }
      this.activeLocks.delete(lockId);
      this.bookings.set(booking.id, booking);
      this.idempotencyRecords.set(idempotencyKey, booking);
      return booking;
    });
  }

  async cancelBooking(bookingId: string): Promise<void> {
    return this.serviceMutex.runExclusive(async () => {
      const booking = this.bookings.get(bookingId);
      if (!booking) throw new Error(`Unknown booking ${bookingId}`);
      await booking.cancel();
      this.waitlistNotifier.notifyWaiting(booking.seats);
    });
  }
}

async function main(): Promise<void> {
  const seats: Seat[] = [
    new Seat('A1', SeatCategory.PREMIUM), new Seat('A2', SeatCategory.PREMIUM),
    new Seat('B1', SeatCategory.GOLD), new Seat('B2', SeatCategory.GOLD),
    new Seat('C1', SeatCategory.SILVER), new Seat('C2', SeatCategory.SILVER),
  ];
  const screen = new Screen('SCR-1', 'Screen 1', seats);
  const movie = new Movie('MOV-1', 'Interstellar', 169);
  const show = new Show('SHOW-1', movie, screen, 19); // peak hour

  const waitlistNotifier = new WaitlistNotifier();
  waitlistNotifier.subscribe(new ConsoleWaitlistNotifier());
  const bookingService = new BookingService(new CategoryTimeBasedPricingStrategy(), waitlistNotifier);

  const alice = new User('u1', 'Alice');
  const bob = new User('u2', 'Bob');

  // "Concurrency" demo: Alice holds {A1,A2}, Bob holds {A2,B1} -- overlapping sets racing via Promise.allSettled.
  const [aliceResult, bobResult] = await Promise.allSettled([
    bookingService.holdSeats(alice, show, ['A1', 'A2']),
    bookingService.holdSeats(bob, show, ['A2', 'B1']),
  ]);
  if (bobResult.status === 'rejected') console.log("Bob's hold rejected (expected, contends on A2):", (bobResult.reason as Error).message);
  const aliceLock = (aliceResult as PromiseFulfilledResult<SeatLock>).value;
  console.log('Alice locked seats:', aliceLock.seats.length);

  const booking = await bookingService.confirmBooking(aliceLock.id, { success: true }, 'idem-key-1');
  console.log(`Booking ${booking.id} CONFIRMED, total=${booking.totalPrice.toFixed(2)}`);

  const retry = await bookingService.confirmBooking(aliceLock.id, { success: true }, 'idem-key-1');
  console.log('Idempotent retry returns same booking:', retry === booking);

  const bobLock = await bookingService.holdSeats(bob, show, ['B1', 'B2']);
  const failedPayment = await bookingService.confirmBooking(bobLock.id, { success: false }, 'idem-key-2');
  console.log("Bob's failed-payment booking status:", failedPayment.status, '(seats released, waitlist notified)');

  await bookingService.cancelBooking(booking.id);
  console.log('A1 status after cancellation:', show.getShowSeat('A1').status);
  console.log('A2 status after cancellation:', show.getShowSeat('A2').status);

  const shortLock = await bookingService.holdSeats(alice, show, ['C1']);
  await new Promise<void>((resolve) => setTimeout(resolve, 2100));
  try {
    await bookingService.confirmBooking(shortLock.id, { success: true }, 'idem-key-3');
  } catch (e) {
    console.log('Expired hold correctly rejected:', (e as Error).message);
  }
  console.log('C1 status after expiry:', show.getShowSeat('C1').status);
}

main().catch((e) => { console.error(e); process.exit(1); });
