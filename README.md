# LLD / OOD Interview Handbook

A static, multi-page reference covering 20 classic low-level design interview problems (Parking Lot, LRU Cache, Rate Limiter, Splitwise, Ride-Sharing, and more), each broken into requirements, entities, class diagrams, design patterns, concurrency, scaling, trade-offs, pseudocode, and testing strategy -- plus a cross-problem synthesis page.

Includes sidebar navigation, client-side search, a difficulty filter, dark mode, copy-to-clipboard code blocks, and a mobile-responsive layout.

## Regenerating

This site is generated from `../lld-handbook.html` (the single-page source document). To rebuild after editing that source:

```bash
python3 build.py
```
